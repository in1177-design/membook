# ספר זיכרון — פיילוט

תיעוד התכנון נמצא בתיקיית `docs/`:

- `docs/תכנון-ארכיטקטורה-טכנית.md` — ארכיטקטורה טכנית מלאה (סטאק, מודל נתונים, אבטחה, פריסה).
- `docs/מפת-דרכים.md` — מפת דרכים Now/Next/Later, סיכונים ותלויות.
- `docs/בריף-בנייה-פיילוט.md` — בריף תמציתי להעברה לקלוד קוד: היקף v1, מה בפנים/מה בחוץ, אפיון מסכים.
- `docs/PRD-פיילוט-איסוף-חומרים.md` — PRD מפורט: מטרות, משתמשים, דרישות P0/P1/P2, מדדי הצלחה, שאלות פתוחות.
- שני קבצי PDF ברקע — הרעיון המקורי והסיכום העסקי מהשלב המוקדם יותר.

## איך להתחיל עם קלוד קוד

1. לפתוח טרמינל בתיקיית הפרויקט הזו (`K:\projects\book_mem`).
2. להריץ `claude`.
3. ההנחיה הראשונה יכולה להיות פשוט: "תקרא את כל הקבצים בתיקיית docs/ ותתחיל לבנות לפי הבריף והארכיטקטורה שם."

## היקף v1 בקצרה
עמוד אדמין (דסקטופ קודם, אבל נפתח גם בנייד) עם הוספת קרוב (כולל איש קשר שני אופציונלי) וטבלת מעקב סטטוסים; עמוד מוזמן ציבורי (מובייל קודם) עם 1-2 שאלות ברירת מחדל, שדה טקסט, והעלאת תמונה (גלריה+מצלמה). בלי CSV, בלי Twilio, בלי טיוטה, בלי ריבוי אדמינים — בכוונה, לפיילוט מהיר על משפחה קטנה.
