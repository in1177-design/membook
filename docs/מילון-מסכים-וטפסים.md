# מילון מסכים, חלונות וטפסים — ספר זיכרון

**עודכן:** 3.8.2026
**מטרת המסמך:** לתת שם/קוד קצר לכל דף, חלון (מגירה/תפריט) וטופס במערכת, כדי שיהיה קל לתשר עליהם בשיחה ("תעדכני את D4", "בואי נשנה את F2") בלי לתאר כל פעם מחדש איפה זה נמצא.

הקודים: **P** = דף (Page), **D** = מגירה/פאנל (Drawer), **M** = תפריט נפתח (Menu), **C** = ציפ לחיץ בטבלה (Chip), **N** = חלון אישור מחיקה (Native confirm), **F** = טופס (Form).

## 1. דפים (P)

| קוד | שם | כתובת (route) | מה יש בו |
|---|---|---|---|
| **P1** | דף כניסה | `/admin/login` | שדה סיסמה + כפתור כניסה |
| **P2** | דף רשימת פרויקטים | `/admin/projects` | רשת כרטיסי כל הפרויקטים, כפתור "+ פרויקט חדש" |

## 4. מפת קשרים מהירה

```
P2 (רשימת פרויקטים)
 ├─ D1 → F2  (יצירת פרויקט)
 └─ D2 → F3  (עריכת פרויקט)

P3 (דף פרויקט)
 ├─ D3 → F3  (הגדרות/עריכת פרויקט)
 ├─ M1        (פעולות פרויקט: ZIP, סגירה/פתיחה)
 └─ טבלת מוזמנים
     ├─ M2 → D4 → F4  (הוספת מוזמן)
     ├─ M2 → D5 → F6  (ייבוא מגוגל שיטס)
     ├─ D6 → F5        (עריכת מוזמן, מאייקון עיפרון)
     ├─ D7              (צפייה בתשובות, מלחיצה על שם)
     ├─ D8              (תצוגה מקדימה, מאייקון עין)
     ├─ M3 → N1         (מחיקת מוזמן)
     ├─ C1               (ציפ שפה)
     └─ C2               (ציפ נוכחות)

P4 (עיצוב האלבום) — גרירת כפולות, ללא חלונות

P5 (דף המוזמן, ציבורי) → F7 (טופס הגשה)
```
